# Z-Frame Bicycle – SAE Bicycle Design Challenge

## Project Overview

Designed and developed a lightweight and compact **Z-frame bicycle** for the **SAE Bicycle Design Challenge 2025–26** as part of **Team Pegasus (BDC2025020)**.

The project focused on:

- Z-frame design
- Structural stability
- Rider comfort
- Lightweight construction
- Sustainable materials
- Urban usability

## Key Features

- Z-frame structure
- Spring-based seat suspension
- Ergonomic handlebar
- Mechanical braking system
- Platform pedals
- Side-mounted kickstand
- Standard wheels and tyres
- Corrosion-resistant frame material

# Hardware

This folder contains the main hardware and mechanical components used in the Z-Frame Bicycle.

## Main Components

- Z-frame structure
- CR (Cold Rolled) frame material
- Spring-based seat suspension
- Mechanical braking system
- Ergonomic handlebar
- Platform pedals
- Standard wheels and urban tyres
- Side-mounted kickstand

## Design Focus

The hardware selection was based on:

- Strength
- Durability
- Rider comfort
- Safety
- Easy maintenance
- Manufacturability
- Sustainable material use

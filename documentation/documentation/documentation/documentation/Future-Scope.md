# Future Scope

The Z-Frame Bicycle can be further improved in the following areas:

## 1. Frame Optimization

- Further optimize the Z-frame geometry.
- Reduce weight while maintaining structural strength.
- Improve joint and frame durability.

## 2. Suspension Improvement

- Optimize the spring suspension system.
- Improve shock absorption on uneven roads.
- Study different spring configurations.

## 3. Material Improvement

- Explore lightweight and recyclable materials.
- Compare different frame materials for strength and weight.
- Improve corrosion resistance.

## 4. Rider Comfort

- Further optimize seat position.
- Improve handlebar ergonomics.
- Improve riding comfort for different rider heights.

## 5. Braking System

- Improve braking response.
- Study lightweight braking components.
- Evaluate braking performance under different conditions.

## 6. Safety and Stability

- Further evaluate steering geometry.
- Improve stability during maneuvering.
- Conduct additional practical testing.

## 7. Manufacturing

- Improve fabrication accuracy.
- Optimize component assembly.
- Reduce manufacturing complexity and cost.

## 8. Future Testing

Future testing can include:

- Durability testing
- Load testing
- Maneuverability testing
- Road-condition testing
- Long-duration riding tests

## Future Goal

The main goal is to develop a **lighter, stronger, safer, more comfortable and sustainable bicycle** for urban transportation.

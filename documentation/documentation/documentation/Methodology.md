# Design Methodology

## 1. Overview

The Z-Frame Bicycle project followed a systematic design and development approach for creating a lightweight and practical urban bicycle.

The methodology involved:

- Concept development
- Design planning
- CAD modelling
- Component selection
- Prototype development
- Testing and improvement

---

# 2. Concept Development

The initial stage focused on identifying the requirements of the bicycle.

Main objectives:

- Develop an innovative Z-frame design
- Maintain structural stability
- Improve rider comfort
- Reduce unnecessary weight
- Create a practical urban bicycle

---

# 3. Frame Design Process

The frame design was developed considering:

- Rider ergonomics
- Structural strength
- Manufacturing feasibility
- Compact design
- Component placement

The Z-frame structure was selected as the main design concept.

---

# 4. CAD Modelling

The bicycle model was developed using CAD software.

The CAD process included:

- Frame modelling
- Component assembly
- Geometry development
- Design modification
- Final model preparation

The design was evaluated through different views:

- Side view
- Front view
- Top view
- Isometric view

---

# 5. Component Selection

The major components were selected based on:

- Strength requirements
- Weight consideration
- Cost effectiveness
- Availability
- Practical usage

Selected components:

- CR frame material
- Spring seat suspension
- Mechanical brakes
- Ergonomic handlebar
- Platform pedals
- 26-inch wheels
- Side-mounted kickstand

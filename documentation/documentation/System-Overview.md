# System Overview

## 1. Project Introduction

The **Z-Frame Bicycle** was designed and developed for the **SAE Bicycle Design Challenge 2025–26** by **Team Pegasus (BDC2025020)**.

The project focuses on developing a lightweight, comfortable and practical urban bicycle with an innovative **Z-frame structure**.

The design aims to improve:

- Structural stability
- Rider comfort
- Compactness
- Ease of use
- Sustainability

# CAD Design

This folder contains the CAD models and engineering drawings of the Z-Frame Bicycle.

## CAD Work

- Z-frame bicycle assembly
- Frame design
- Pedal design
- Tyre and wheel design
- Front and side views
- Detailed component drawings
- 3D model development

## Design Features

- Compact Z-frame structure
- Improved weight distribution
- Ergonomic rider position
- Spring suspension below the seat
- Practical urban bicycle geometry

## Engineering Geometry

- Head tube angle: 71°
- Seat tube angle: 73°
- Chain stay length: 17 inches
- Wheel size: 26 inch
- Ground clearance: 11 inches
- Toe clearance: 6.5 inches

Recommended CAD file formats:

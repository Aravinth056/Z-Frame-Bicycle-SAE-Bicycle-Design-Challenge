# Results

This folder contains the testing and evaluation results of the Z-Frame Bicycle.

## Evaluation Areas

- Maneuverability
- Rider control
- Stability
- Comfort
- Steering response
- Braking performance
- Prototype usability

## Competition Result

The bicycle participated in the **SAE Bicycle Design Challenge 2025–26** as part of **Team Pegasus (BDC2025020)**.
